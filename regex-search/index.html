About this tool

Regex Search uses your browser's JavaScript regular-expression engine and always searches globally, so every match is listed with its start index, length, matched value and capture groups — both numbered ($1, $2…) and named ((?<name>…)).

Flags

  • i — case-insensitive matching.
  • m — ^ and $ match at every line break.
  • s — . also matches newlines (single-line / dotall mode).
  • u — full Unicode: code-point escapes like \u{1F600} and property classes like \p{L}.

Limits

The table shows the first 500 matches; counting stops at 100,000 matches or after about one second. Empty matches (such as a* between characters) are shown as thin markers and the search moves on by one character (one code point with the u flag), so it never loops forever. Matching runs in a background worker: a pathological pattern such as (a+)+$ is stopped after 1.5 seconds and the page stays responsive.

Privacy

All processing happens in your browser. Nothing you type is sent, stored or logged.
