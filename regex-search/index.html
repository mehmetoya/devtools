About this tool

Regex Search uses your browser's JavaScript regular-expression engine and always searches globally, so every match is listed with its start index, length, matched value and capture groups — both numbered ($1, $2…) and named ((?<name>…)).

Flags

  • i — case-insensitive matching.
  • m — ^ and $ match at every line break.
  • s — . also matches newlines (single-line / dotall mode).
  • u — full Unicode: code-point escapes like \u{1F600} and property classes like \p{L}.

Limits

The table shows the first 500 matches; counting stops at 100,000 matches or after about one second. Empty matches (such as a* between characters) are shown as thin markers and the search moves on by one character (one code point with the u flag), so it never loops forever. Matching runs in a background worker: a pathological pattern such as (a+)+$ is stopped after 1.5 seconds and the page stays responsive.

Privacy

All processing happens in your browser. Nothing you type is sent, stored or logged.

Questions

How do I test a regular expression online?

Type a pattern, paste your test text, and every match is highlighted and listed with its index, length, value and capture groups. Both numbered groups ( ,

) and named groups ((?<name>…)) are shown. The tool uses your browser's JavaScript regex engine, so results match what String.prototype.matchAll returns in JavaScript. Matching runs locally; nothing is uploaded.

What do the g, i, m, s and u regex flags do?

g finds all matches instead of the first; this tool always searches globally. i ignores case, and m makes ^ and $ match at every line break. s lets . match newlines, and u enables full Unicode, including \u{1F600} escapes and property classes such as \p{L}. The u flag is on by default.

Why does my regex hang or time out?

Nested quantifiers such as (a+)+$ can cause catastrophic backtracking, where the engine tries an exponential number of paths. This page runs matching in a background worker and stops it after 1.5 seconds, so the page stays responsive. Make quantifiers more specific or remove the nesting to fix the pattern.

How many matches can it show?

The results table shows the first 500 matches, and counting stops at 100,000 matches or after about one second. Empty matches, such as a* between characters, appear as thin markers and the search advances one character, so it never loops forever. Use "Show matches only" to copy or download all matched values, one per line.
