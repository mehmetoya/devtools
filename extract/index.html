String Extract

Pull out part of a text by position, between delimiters, with a regex group, or by line numbers.

About this tool

String Extract pulls a piece of text out using one of four strategies. Multiple results are placed on separate lines.

Modes

  • Substring — characters from a 0-based Start position, for Length characters (empty = to the end). A negative start counts from the end, so -4 takes the last four characters.
  • Between — text between a start and an end delimiter, optionally including the delimiters, first occurrence or all of them. An empty start delimiter means "from the beginning", an empty end delimiter "to the end".
  • Regex — every match of a JavaScript regular expression; choose which capture group to output (0 = the whole match). Unicode (u) is on by default (enables \p{L} and treats emoji as single characters). Matching runs in a background worker and a pattern that takes longer than 1.5 seconds is stopped.
  • Lines — line numbers and ranges such as 1-5, 10, 15-20. Line numbers start at 1; 12- means line 12 to the end. Lines are output in the order the ranges are listed.

Privacy

All processing happens in your browser. Nothing you type is sent, stored or logged.

Questions

How do I extract text between two delimiters?

Choose Between mode and enter a start and an end delimiter, for example [ and ]. You can include the delimiters in the output and take the first occurrence or all of them, one per line. An empty start delimiter means from the beginning of the text, and an empty end delimiter means to the end.

How do I extract a substring by position?

Use Substring mode with a 0-based Start and an optional Length; leave Length empty to take everything to the end. A negative start counts from the end, so Start -4 returns the last four characters. Positions count Unicode code points, so an emoji counts as one character.

How do I extract only a capture group from regex matches?

Choose Regex mode, enter a JavaScript pattern and set Group to the capture group you want, where 0 is the whole match. For example, pattern order=(\d+) with Group 1 lists just the order numbers, one per line. Matching runs in a background worker and stops after 1.5 seconds.

How do I get specific lines from a text?

Use Lines mode and enter line numbers or ranges such as 1-5, 10, 15-20. Line numbers start at 1, and an open range like 12- takes line 12 to the end. Lines are output in the order the ranges are listed.
