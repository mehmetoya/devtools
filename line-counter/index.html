Line Counter

Live statistics for any text: lines, words, characters, bytes, paragraphs and sentences.

Text

How things are counted

  • Lines — every line break (\n, \r\n or \r) starts a new line. A trailing line break therefore adds an empty last line, just as most editors show it.
  • Non-empty lines — lines that contain at least one non-whitespace character.
  • Words — runs of characters separated by whitespace.
  • Characters — Unicode code points, so an emoji such as 😀 counts once. No spaces leaves out all whitespace including line breaks.
  • Bytes — the size of the text when saved as UTF-8.
  • Paragraphs — blocks of text separated by one or more blank lines.
  • Sentences — detected with the browser's built-in sentence segmentation.
  • Avg word length — letters and digits per word, ignoring punctuation.

Privacy

All processing happens in your browser. Nothing you type is sent, stored or logged.

Questions

How do I count lines, words and characters in a text?

Paste or type the text and the statistics update live: lines, non-empty lines, words, characters, bytes, paragraphs, sentences and average word length. Use Copy stats or Download stats to export them. The text is counted in your browser and never sent anywhere.

Why is the line count one higher than I expected?

A trailing line break starts a new, empty last line, the same way most editors display it. So a, line break, b, line break counts as 3 lines. Check Non-empty lines if you only want lines that contain visible text.

What is the difference between characters and bytes?

Characters are Unicode code points, so an emoji counts as one. Bytes are the size of the text saved as UTF-8, where non-ASCII characters take more space: é is 2 bytes and 😀 is 4. Byte counts matter for size limits in databases and APIs.

How are words and paragraphs counted?

Words are runs of characters separated by whitespace. Paragraphs are blocks of text separated by one or more blank lines. Sentences are detected with the browser's built-in sentence segmentation, so results can differ slightly between languages.
