About this tool

Base64 represents binary data with 64 printable ASCII characters. The text is first converted to bytes with the selected encoding, then those bytes are Base64-encoded. Decoding reverses the process.

Privacy

All processing happens in your browser. Nothing you type is sent, stored or logged.
