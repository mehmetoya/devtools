About this tool

JSON Compare parses both documents and walks them side by side. Instead of a line-based text diff, it reports semantic differences, so whitespace, indentation and key order inside objects never count as changes.

Difference types

  • added — the path exists only in B.
  • removed — the path exists only in A.
  • changed — same type, different value.
  • type mismatch — e.g. a number in A and a string in B (only reported in strict mode for primitives).
  • array length — the arrays at this path have different lengths.

Options

Ignore array order matches array items by value, so [1,2,3] and [3,1,2] are equal; it stays fast on arrays with thousands of items. Strict types off treats primitives with the same text or numeric value as equal (1 vs "1", true vs "true").

Numbers and duplicate keys

Numbers are compared exactly as written, not as rounded floating-point values: 12345678901234567890 and 12345678901234567891 are different, while 1 and 1.0 are the same number. If a document repeats a key in one object, the later value is compared (as most parsers do) and a warning names the key and line.

Privacy

All processing happens in your browser. Nothing you paste is sent, stored or logged.
