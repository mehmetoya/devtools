    About GUIDs and UUIDs

    A GUID (Microsoft's name) or UUID is a 128-bit identifier written as 32 hexadecimal digits. Four bits encode the version (the first digit of the third group) and two or three bits the variant (the first digit of the fourth group: 8, 9, a or b for standard UUIDs).

    • Version 4 is 122 bits of randomness. This page uses crypto.randomUUID(), the browser's cryptographically secure generator. In .NET: Guid.NewGuid().
    • Version 7 (RFC 9562) starts with a 48-bit Unix timestamp in milliseconds followed by random bits, so values sort by creation time and index well in databases. In .NET 9+: Guid.CreateVersion7(). Values generated in the same millisecond here are kept in increasing order.
    • .NET format letters: D hyphens (default), N digits only, B braces, P parentheses, X hex structure as used in C/C# initialisers.
    • Guid.ToByteArray() stores the first three groups little-endian, which is why the bytes look shuffled compared to the string.
    • The nil GUID (Guid.Empty) is all zeros; the max UUID is all f.
