    About JSON Web Tokens

    A JWT is three Base64URL segments joined by dots: a header naming the algorithm, a payload holding the claims, and a signature computed over the first two parts. Anyone can read the header and payload; only the signature proves who created the token.

    • iat (issued at), exp (expiration) and nbf (not before) are Unix timestamps in seconds.
    • This tool signs and verifies with HMAC (HS256, HS384, HS512) through the browser's Web Crypto API. Signature comparison is done by crypto.subtle.verify.
    • Tokens using alg: none are always reported as invalid. RSA/ECDSA tokens can be decoded but not verified here.
    • RFC 7518 asks for an HMAC secret at least as long as the hash output (32 bytes for HS256, 48 for HS384, 64 for HS512).

    Privacy

    Tokens and secrets are processed only in your browser. Nothing is sent, stored or logged. Even so, avoid pasting production secrets into any web page you do not control.

    Questions

    How do I decode a JWT token?

    Switch to Decode and paste the token. The header and payload are shown as JSON, and time claims such as exp and iat are listed alongside. Decoding does not check the signature; use Validate for that.

    How do I verify a JWT signature?

    Switch to Validate, paste the token and enter the secret, ticking Secret is Base64 encoded if needed. The tool verifies HS256, HS384 and HS512 signatures and can also check expiry, not-before, issuer and audience with a configurable clock skew. RSA and ECDSA tokens can be decoded but not verified here.

    Is the data in a JWT encrypted?

    No. A standard JWT is three Base64URL segments, so anyone holding the token can read the header and payload. Only the signature proves who created it. Never put secrets in the claims.

    How long should an HS256 secret be?

    RFC 7518 asks for an HMAC key at least as long as the hash output: 32 bytes for HS256, 48 for HS384 and 64 for HS512. The tool warns when a secret is shorter, and the Random button generates one. Avoid pasting production secrets into web pages you do not control.
