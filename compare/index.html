About this tool

The comparison anchors on lines that occur exactly once in both texts, then aligns the stretches between them with the Myers algorithm — so it finds the lines the two texts share and reports everything else as removed (−, only in A) or added (+, only in B). Because it aligns on common lines, inserting one line near the top does not flag the rest of the document. When a removed line is directly replaced by an added one, the exact characters that differ are highlighted.

  • Ignore case treats upper- and lower-case letters as equal.
  • Ignore whitespace disregards all spaces and tabs inside lines.
  • Trim lines only ignores whitespace at the start and end of each line.

Copy and Download export the result as plain text with - / + markers. Windows and Unix line endings compare as equal.

Privacy
