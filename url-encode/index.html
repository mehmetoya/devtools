About this tool

URLs may only contain a limited set of ASCII characters. Everything else is converted to UTF-8 bytes and written as %XX hex pairs.

  • Component encodes every reserved character, including / ? # & =. Use it for a single query value or path segment (like encodeURIComponent).
  • Full URL keeps the characters that give a URL its structure and only encodes the rest (like encodeURI). When decoding, escapes of reserved characters such as %2F are left in place.
  • + for spaces follows HTML form encoding (application/x-www-form-urlencoded): spaces become + and ! ' ( ) ~ are escaped too. A literal + is written as %2B in both modes, so it is not mistaken for a space. When decoding, + is read as a space and %2B as a plus sign.

The breakdown panel parses the first line of the input (or the decoded output) as an absolute URL and lists its components and decoded query parameters.

Privacy

All processing happens in your browser. Nothing you type is sent, stored or logged — the URL is only parsed, never requested.
