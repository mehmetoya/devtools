URL Encode / Decode

Percent-encode text for safe use in URLs, decode encoded strings, and break a URL into its parts.

About this tool

URLs may only contain a limited set of ASCII characters. Everything else is converted to UTF-8 bytes and written as %XX hex pairs.

  • Component encodes every reserved character, including / ? # & =. Use it for a single query value or path segment (like encodeURIComponent).
  • Full URL keeps the characters that give a URL its structure and only encodes the rest (like encodeURI). When decoding, escapes of reserved characters such as %2F are left in place.
  • + for spaces follows HTML form encoding (application/x-www-form-urlencoded): spaces become + and ! ' ( ) ~ are escaped too. A literal + is written as %2B in both modes, so it is not mistaken for a space. When decoding, + is read as a space and %2B as a plus sign.

The breakdown panel parses the first line of the input (or the decoded output) as an absolute URL and lists its components and decoded query parameters.

Privacy

All processing happens in your browser. Nothing you type is sent, stored or logged — the URL is only parsed, never requested.

Questions

How do I URL-encode a query parameter value?

Choose Encode and the Component mode, which escapes every reserved character like encodeURIComponent. For example, a b&c=1 becomes a%20b%26c%3D1, so it can be placed safely after ?q=. Non-ASCII text is converted to UTF-8 bytes first: café becomes caf%C3%A9.

What is the difference between Component and Full URL encoding?

Component encodes everything reserved, including / ? # & =, and suits a single value or path segment. Full URL keeps the characters that give a URL its structure and encodes only the rest, like encodeURI. When decoding in Full URL mode, escapes such as %2F are left in place.

Should spaces be encoded as %20 or +?

Use %20 in paths and general URLs. + for spaces is only correct in HTML form encoding (application/x-www-form-urlencoded); turn on + for spaces for that. A literal plus sign is always written as %2B so it is not read as a space.

How do I see the query parameters of a long URL?

Paste the URL and check the URL breakdown panel. It parses the first line as an absolute URL and lists its components and decoded query parameters. The URL is only parsed locally, never requested.
