About this tool

      
A free JSON formatter, beautifier, validator and minifier. Paste JSON (or drop a .json file on the input) and it is re-formatted as you type, with color-coded keys, strings, numbers, booleans and null values. Switch the action to minify, sort keys at every nesting level, or convert an array of objects into CSV.

Keyboard shortcuts

      
Ctrl+Enter (⌘+Enter on Mac) runs the selected action · Esc closes fullscreen.

      
Privacy & security

      
All JSON is processed in your browser by a strict, lossless parser that runs on the page. Nothing is sent to a server, stored, or logged, and there is no share or history feature. The highlighted output is built with DOM text nodes only — never innerHTML — so a malicious payload cannot inject markup or scripts.

    

    
    

      
Questions

      
How do I find where my JSON is invalid?

      
Paste the JSON and choose Validate. The tool reports the exact line and column of the first syntax error with a hint on how to fix it, such as a trailing comma or single quotes instead of the double quotes JSON requires.

      
How do I minify JSON?

      
Choose Minify to strip all whitespace for transport. The size stats show the original and result in UTF-8 bytes and the difference. Beautify reverses it with 2 spaces, 4 spaces or tabs.

      
Does formatting change large numbers in my JSON?

      
No. The parser is lossless, so numbers are written exactly as in the input; 12345678901234567890 and 1e400 stay intact rather than being rounded. Duplicate keys are kept and reported instead of silently dropped.

      
How do I convert JSON to CSV?

      
Choose To CSV with an array of objects (or a single object) as input. Every key found across the objects becomes a column, missing values are left empty, and nested objects or arrays are written as JSON inside the cell. Download saves the result as .csv.
