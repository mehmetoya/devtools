About this tool

A cryptographic hash function maps any input to a fixed-size fingerprint. Text is encoded as UTF-8 before hashing, so the same string always produces the same digest as most command-line tools (for example printf %s "text" | sha256sum).

  • MD5 (128 bits) and SHA-1 (160 bits) are broken for collision resistance. Use them only for checksums and legacy compatibility.
  • SHA-256, SHA-384 and SHA-512 belong to the SHA-2 family and are suitable for integrity checks and signatures.
  • HMAC mixes a secret key into the hash so only key holders can produce or check the value. HMAC-MD5 is computed in JavaScript; the SHA variants use the browser's Web Crypto API.
  • Plain hashes are not a safe way to store passwords. Use a slow, salted algorithm such as Argon2, scrypt or bcrypt.

Verify

Paste any digest into the verify box. It is compared (case-insensitively for hex) against every algorithm for the current input and the matching algorithm is highlighted.

Privacy

Text, files and keys stay in your browser. Nothing is uploaded, stored or logged.
