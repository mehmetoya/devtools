JSON to Java

Generate Java classes or records from a JSON sample.

JSON input
Java code

About this tool

Paste a JSON sample and get a single compilable .java file: the root class plus every nested object as a public static inner class (or nested record). When the root is an array of objects, the item type is generated.

Type mapping

  • Whole numbers → Integer, Long outside the 32-bit range, BigInteger beyond 64 bits; numbers with a decimal point or exponent → Double.
  • true/false → Boolean; text → String; arrays → List<T>.
  • null-only values, empty arrays and mixed arrays → Object.
  • Field names are camelCased; Java keywords and names of Object methods (hashCode, toString, getClass, wait…) get a trailing underscore. Keep Jackson on so the original JSON names still map.

Options

Records (Java 16+) produce immutable records, so Lombok and accessors are disabled. Lombok @Data generates accessors at compile time instead of writing them out.

Privacy

Code is generated entirely in your browser. The JSON you paste is never uploaded, stored or logged.

Questions

How do I convert JSON to a Java POJO?

Paste a JSON sample and set the Class name and optional Package. You get one compilable .java file with the root class and every nested object as a public static inner class. Arrays become List<T>.

Can I generate Java records or Lombok classes from JSON?

Yes. Records (Java 16+) produce immutable records, which disables Lombok and accessors. Lombok @Data adds the annotation so accessors are generated at compile time; otherwise Getters / setters writes them out.

How are JSON field names mapped to Java?

Field names are camelCased, and Java keywords or Object method names such as class or hashCode get a trailing underscore. Keep Jackson @JsonProperty on so the original JSON names still map during deserialization.

Which Java types are used for JSON numbers?

Whole numbers become Integer, Long outside the 32-bit range and BigInteger beyond 64 bits. Numbers with a decimal point or exponent become Double. Booleans map to Boolean, text to String, and null-only or mixed values to Object.
