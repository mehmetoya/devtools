About this tool

Mermaid turns short text descriptions into diagrams. Start a document with the diagram type — flowchart, sequenceDiagram, classDiagram, stateDiagram-v2, erDiagram, gantt, pie, gitGraph or mindmap — then add nodes and connections. Pick a template to see a working example of each.

Diagrams render in strict security mode: HTML inside labels is escaped and click handlers are disabled. PNG export is drawn at twice the diagram's size for sharp results; SVG keeps the diagram fully scalable and editable.

Privacy

The diagram engine runs locally in your browser. Your code is never uploaded; a draft is kept in this browser between visits.
