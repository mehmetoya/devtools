About this tool

The preview is an <iframe> sandbox with a unique, opaque origin. Scripts inside it may run (unless you turn on Sanitize HTML), but they cannot read this site's storage or cookies, open pop-ups, submit forms, show alert dialogs or navigate this page.

The preview inherits this site's security policy: inline <style> and <script> work, while external scripts, stylesheets, fonts and remote images are blocked. Embed images as data: URLs if you need them.

Sanitize HTML removes <script> elements, inline event handlers such as onclick and javascript: links — handy for previewing HTML from an untrusted source, such as an email body.

Privacy

Your HTML is rendered locally and never uploaded. A draft is kept in this browser between visits.
